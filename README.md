## Featured projects

### Autonomous Delivery Robot

A delivery robot prototype connecting a web control interface and Android navigation with embedded motor control, obstacle sensing, and a lockable compartment.

**Technologies:** C++ · Arduino Mega · ESP8266 · React · Firebase · Java / Android  
[Repository](https://github.com/DannarZharkyn/delivery-robot) · [Portfolio](https://dannarzharkyn.github.io/projects/autonomous-delivery-robot/)

### Terrier Pursuit

A campus scavenger hunt platform for Boston University Student Wellbeing, with event management, QR participation, and participant progress tracking.

**Technologies:** Next.js · React · TypeScript · Tailwind CSS · Supabase  
[Repository](https://github.com/DannarZharkyn/terrier-pursuit-prototype) · [Portfolio](https://dannarzharkyn.github.io/projects/terrier-pursuit/)

### Somni Systems

**Website technologies:** HTML · CSS · JavaScript
